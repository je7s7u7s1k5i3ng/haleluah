## 0. 규칙
1. **읽기 전용 점검**. 코드·설정·영상은 수정·삭제·재렌더하지 않는다. 결과는 `점검\` 아래 새 파일로만.
2. 판정마다 증거(파일:줄, 설정값, 결과물 경로). 못 찾으면 `없음(검색어 X → 0건)`, 확인 못 하면 `HOLD`.
3. 작동하던 파일·성공 패턴 보존. 모든 결론은 `CANDIDATE`.
4. 채널 연출 기준: 성적 장면·노출, 성별 전환 연출, 동성 연애 묘사는 생성·합성 대상에서 제외(샤오홍슈 점검과 동일 기준).

## 1. 먼저 파악할 것
| 단계 | 할 일 |

| 1-3 | 쓰는 AI 도구·모델과 판본(로컬 모델 / 클링·힉스필드·Veo 등 클라우드) 목록 |
| 1-4 | 실행 PC 사양 확인 (보조 PC 그래픽카드가 GTX 1650 4GB면 무거운 로컬 모델은 못 돈다 → 클라우드 분기 필요 여부) |
