# 터진 주제 → 유튜브 교차 분석 파이프라인 v1.0

"**오늘 경제 터진 주제로 수집해줘**" 한 마디로:

```
① 뉴스에서 오늘 터지는 주제를 숫자로 측정
   (24시간 기사 수 · 동시 보도 매체 수 · 지난 7일 대비 급상승 · 네이버 검색 급상승)
② 주제별 유튜브 영상 수집: 메타데이터(조회·좋아요·댓글·구독자·길이) + 썸네일 이미지 + 대본(자막)
③ 교차 검증: 뉴스 주제 ↔ 제목 ↔ 설명 ↔ 대본, 뉴스 숫자가 대본에 나오는지, 제목 약속이 첫 60초에 나오는지
④ 터진 영상(조회/구독 상위 25%) vs 나머지: 제목·썸네일·대본·길이 특징 차이
⑤ 결과\YYYYMMDD_HHMM_경제\보고서.md
```

---

## 1. 설치 — `J:\프로그램 관리\기사들 수집하는 프로그램` 한 폴더로

폴더 구성 (이 저장소에서 그대로 복사):
```
J:\프로그램 관리\기사들 수집하는 프로그램\
 ├─ trend_pipeline\          ← 프로그램 (폴더째 복사)
 ├─ 오늘_터진주제_수집.bat   ← 더블클릭 실행
 ├─ requirements.txt
 ├─ config.json              ← (선택) 설정
 ├─ 결과\                    ← 자동 생성: 회차별 결과
 ├─ data\                    ← 자동 생성: 급상승 기준선·중복 기록 (지우지 말 것)
 └─ logs\                    ← 자동 생성: 실행 기록
```
- 기존 파일과 이름이 겹치면 **덮어쓰지 말고** 먼저 확인한다(작동하던 파일 보존).
- 기존 `news_collector.py`는 그대로 둔다. 터진 주제 측정은 이 파이프라인이 맡는다.

설치 명령 (그 폴더에서 1회):
```
pip install -r requirements.txt
```

## 2. 키 (PC 환경변수로 넣기 — 파일에 적지 않기)

| 키 | 없으면 | 넣는 법 (명령창 1회, 새 창부터 적용) |
|---|---|---|
| `YOUTUBE_API_KEY` | 유튜브 단계 HOLD (뉴스 주제까지만) | `setx YOUTUBE_API_KEY "발급받은키"` |
| `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` | 검색 급상승 HOLD | `setx NAVER_CLIENT_ID "..."` / `setx NAVER_CLIENT_SECRET "..."` |

- 유튜브 키: Google Cloud Console → YouTube Data API v3 사용 설정 → API 키. 하루 기본 10,000단위, 1회 실행(주제 5개) ≈ 510단위.
- 네이버 키: 네이버 개발자센터 → 애플리케이션 등록 → 데이터랩(검색어 트렌드).
- 대본 수집은 `yt-dlp`가 설치돼 있으면 자동으로 켜진다.

## 3. 실행

| 방법 | 명령 |
|---|---|
| 더블클릭 | `오늘_터진주제_수집.bat` (기본: 경제) |
| 자연어 | `python -m trend_pipeline.run 오늘 경제 터진 주제로 수집해줘` |
| 다른 분야 | `python -m trend_pipeline.run --category 건강` (경제·건강·역사) |
| 뉴스만 | `python -m trend_pipeline.run --news-only` |
| 대본 끄기 | `--no-transcripts` |
| 개수 | `--top-topics 5 --videos-per-topic 10` |

`config.json` (선택):
```json
{ "top_topics": 5, "videos_per_topic": 10, "lookback_days": 7, "request_sleep_sec": 1.0, "transcripts": true }
```

`J:\프로그램 관리\기사들 수집하는 프로그램\CLAUDE.md` 에 아래를 추가하면, 그 폴더에서 연 Claude Code에 "오늘 경제 터진 주제로 수집해줘"라고 하면 바로 돈다.

```markdown
## 터진 주제 수집 명령
- "오늘 {경제|건강|역사} 터진 주제로 수집해줘" →
  이 폴더에서 `python -m trend_pipeline.run 오늘 {분야} 터진 주제로 수집해줘` 실행.

  ① 터진 주제 TOP5(점수·매체 수) ② 주제별 터진 영상과 첫 15초 대본 ③ 터진 영상 vs 나머지 차이 ±0.5 이상 특징

- 대본·썸네일은 분석용 로컬 보관만 한다. 재업로드·재배포하지 않는다.
```

## 5. 결과물

| 파일 | 내용 |
|---|---|
| `hot_topics.json` | 주제별 점수·신호값(측정 못 한 신호는 null=HOLD)·헤드라인·뉴스 숫자 |
| `videos.jsonl` | 영상 1개 = 1줄: 메타데이터, 성과(시간당 조회·조회/구독·참여율), 제목·썸네일·대본 특징, 교차 검증, 터짐 여부 |
| `thumbnails\*.jpg` | 썸네일 원본 |
| `transcripts\*.vtt` | 대본(자막) 원본 |
| `보고서.md` | 사람이 읽는 요약 |
| `manifest.json` | 회차 기록 (신호별 OK/HOLD, 유튜브 사용 단위, 상태 CANDIDATE) |

## 6. 점수 계산 (숫자만, 추정 문장 없음)

```
터짐점수 = 100 × Σ(가중치 × 신호/그 회차 최댓값) / Σ(측정된 신호의 가중치)
가중치: 동시 보도 매체 수 0.35 · 기사 수 0.25 · 보도 급상승 0.25 · 검색 급상승 0.15
```
- 측정 못 한 신호는 0점이 아니라 빼고 다시 나눈다(HOLD).
- 보도 급상승은 `data\trend_history.sqlite`에 기록이 쌓인 **2회차부터** 계산된다. 매일 돌릴수록 정확해진다.
- 기사 1건뿐인 사건, 24시간 지난 기사는 터짐 근거에서 제외.

## 7. 지켜지는 규칙

- 구글·네이버·유튜브 차단을 우회하지 않는다(프록시·IP 순환·캡차 풀기 없음). 막히면 HOLD로 남기고 다음 단계로.
- 유튜브 할당량을 넘으면 남은 주제는 HOLD로 두고 보고서까지 마무리한다.
- 대본 수집이 연속 3번 실패하면 그 회차는 대본을 멈춘다.
- 교차 검증에서 "주제 불일치"인 영상은 터짐 분석 근거에서 뺀다.
