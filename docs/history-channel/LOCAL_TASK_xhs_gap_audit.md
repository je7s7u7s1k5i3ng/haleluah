## 0. 규칙

1. **읽기 전용 점검**이다. 폴더 안의 설계도·코드·수집 데이터는 수정·삭제·이동하지 않는다. 결과는 새 파일 2개로만 쓴다(§4).
2. 판정에는 **증거**(파일 경로, 줄 번호, 개수)를 붙인다. 근거가 없는 항목은 `없음(근거: 검색어 X로 0건)`처럼 확인 방법을 남긴다. 확인을 못 했으면 `HOLD`.
3. 작동하던 파일·성공 패턴은 보존한다. 기존 설계도를 덮어쓰지 않는다.
4. 모든 결론은 `CANDIDATE`. 실측(우리 채널 업로드 성과) 전에는 SUCCESS로 올리지 않는다.
5. 수정안에 **워터마크 제거, 남의 영상·이미지 재업로드, 로그인 벽·차단 우회 수집**은 넣지 않는다(저작권·재사용 콘텐츠·약관 위험).
6. **채널 연출 기준 (사장님 지시, 예외 없음)**
   - 다음 장면은 **연출 설계에 넣지 않는다**: 성적인 장면·노출·선정적 묘사, 성경에 어긋나는 장면(남녀 성별이 바뀌는 연출, 남남·여여 연애 묘사 등).
   - 이런 장면이 들어 있는 샘플은 `EXCLUDED_CONTENT`로 표시하고 **내용·연출 패턴 추출 대상에서 제외**한다.
   - 그런 샘플에서도 **품질 기법과 기술 구현만** 떼어 쓸 수 있다(카메라·조명·색보정·편집 리듬·전환·자막 타이포·사운드·VFX·AI 생성 설정). 이때 원 장면의 내용은 기록하지 않고 기법 이름과 파라미터만 남긴다.
   - 역설계 결과물(설계도·프롬프트·콘티)에 위 장면이 다시 들어가지 않도록 §2 X25 필터를 마지막 관문으로 둔다.
