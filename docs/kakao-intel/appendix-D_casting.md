# 부록 D. K-culture 섭외·광고방 분석

**분석 대상**
- 기간: 2024-06 ~ 2026-10
- 메시지 약 4,400건 (봇 메시지 1,876건 포함)

- 공고 유형은 키워드로 자동 분류했기 때문에 건수는 근사치입니다.

## 2. 공고문 표준 템플릿

신뢰도가 높았던 공고는 사업자 정보, 사용처·기간, 지급일을 모두 적었습니다. 이를 바탕으로 만든 템플릿입니다.

```
[제목] (브랜드) ○○ 촬영 모델 ○명 모집 – 출연료 ○○만원
■ 발주처: 상호 / 사업자등록번호
■ 촬영 내용: 상세페이지 사진 + 15~30초 숏폼 / 대사 유무 / 얼굴 노출 비율
■ 일시: ○월 ○일(○) ○시~○시 (최대 ○시간, 초과 시 시간당 ○원)
■ 장소: ○○ 스튜디오 / 교통비·식사 지원 여부
■ 모집 대상: 만 19세 이상(신분증 확인)·조건
■ 준비물: 의상·헤어·메이크업
■ 출연료: 총 ○○만원 (3.3% 공제 전/후 표기)
■ 지급: 촬영 후 ○영업일 이내
■ 사용처·기간: 상세페이지·스마트스토어·유튜브·인스타 / ○개월 (영구 사용 시 별도 단가)
■ 지원 방법: 구글폼 — 이름/나이/프로필/포트폴리오/SNS
■ 마감/결과 통보: ○월 ○일, 선정자만 개별 연락
※ 지원자에게 참가비·예약금을 요구하지 않습니다.
```

## 3. 발주자로 쓸 때 예산 기준 (공고 시세)

**상세페이지·제품 모델**
- 가전 상세페이지 모델: 20~30만
- 의류 피팅: 20~25만
- 얼굴이 나오지 않는 피팅: 3~5만
- 스킨케어 캠페인 + 상세페이지: 50~80만

**식품 관련**
- 건강기능식품 바이럴 광고 배우: 16만 (4시간, 노출 최대 12개월)
- 다이어트 식품 출시 광고: 50만
- 영양제 SNS 광고: 30~35만
- 시식 평가단: 1인 4만 (3시간)

**숏폼 출연**
- 앱 광고용 셀프캠: 7만 + 배달비
- 숏폼 출연: 10~15만
- 집에서 혼자 찍는 UGC: 30~35만 + 제품

**리뷰어**
- 건강기능식품 UGC: 25만 + 제품
- 생활용품 UGC: 15만 + 제품
- 제품 + 매출 10% 수익쉐어 방식도 있었습니다.
- 팔로워 1만 미만 계정은 제품 협찬 + 소액(3~10만)이 현실적입니다.

**유튜브 진행자**: 회당 30~50만

## 4. 공급자로 쓸 때
- **어필리에이트형 제휴**: 가구·리빙 브랜드가 구독자 수와 관계없이 채널 배너 제휴를 모집했습니다. 수수료 10~15%, 랜딩페이지 제공 조건입니다.
- **협찬 수주**: 건강·경제 채널이 제품당 포스팅비, 숏폼 챌린지, 라이브 협찬 공고에 응모할 수 있습니다.
- **기독교 채널**: CCM 뮤직비디오 출연 공고가 올라온 적이 있으니 모니터링할 만합니다.
- **농산물 공급**: 이 방의 공동구매·라이브커머스 셀러에게 우리 농산물을 공급하는 제안이 가능합니다.
- **제작 대행**: 상세페이지·숏폼 촬영 수요가 꾸준해서, "모델 섭외 포함 패키지"로 수주를 시도할 여지가 있습니다.

## 6. 주의
- **선입금 사기**: "참가비·노쇼방지금"을 먼저 받고 잠적하는 사례가 있었고 실제 피해자가 나왔습니다.
  - 대응: 이체확인서 발급 → 경찰 신고 → 피해자 공동 고소 → 예술인지원센터 상담
- **영상시청 알바**: 처음 소액만 지급하고 이후 미지급하는 유형으로, 보이스피싱으로 지목됐습니다.
- **기타 경고 신호**: 회사명이 없는 제안, "월 ○천 보장", 성인 콘텐츠를 숨긴 모델 구인, 무료라면서 세팅비를 따로 받는 경우
- **미지급 대비**: 지급일과 3.3% 공제 여부를 공고·계약서에 적습니다.
- **미성년자**
  - 청소년 모델 상담 링크는 개인정보 수집 목적이 의심됩니다.
  - 발주는 만 19세 이상으로 제한합니다.
- **초상권**
  - 계약서에 매체·기간·재편집·광고 집행·AI 활용 여부를 명시합니다.
  - '영구 사용'을 뒤늦게 요구하면 분쟁이 생길 수 있습니다.
- **생체정보**: 얼굴·손바닥 AI 데이터 수집 공고는 참여와 발주 모두 신중해야 합니다.
- **건강식품 협찬 콘텐츠**: 효능 표현을 쓰지 않고 "유료광고 포함"을 표기합니다.
