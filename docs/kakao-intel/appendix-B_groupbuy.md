# 부록 B. 솔농 공지방 (농산물 공구·새벽시장) 분석

**분석 범위**
- 기간: 2022-02 ~ 2026-10, 메시지 7,733건, 게시일 1,268일
- 게시 주체: 운영자 계정 2개가 거의 전부를 올림
  - 대표 계정: 단품 특가
  - 새벽시장 매니저 계정: 매일 바뀌는 상품 목록
- 사진 2,040건, 동영상 70건
- 수치는 메시지 타임스탬프를 집계한 값이며, 고객 정보는 포함하지 않았습니다.

## 1. 공지 5유형

공통 규칙: 링크가 있는 글의 97%가 **글 1개당 링크 1개**입니다. 글 길이 중앙값은 180자입니다.

**① 오픈 공지 (새벽시장)**
- 순서: 날짜 헤더 → 오늘 브리핑 3~8줄 → 주문방법 → 유의사항 → 카테고리별 리스트
- 상품 한 줄 형식: `🍠산지 품종 등급 중량_가격 [brix]`
- 같은 상품을 중량별로 2~3줄 연속 배치
- 2026년 주문서 양식: `🟦상품명,가격 / 🟦성함 / 🟦번호 / 🟦주소 / *배송메세지`

**② 게릴라·마감임박** ('게릴라' 언급 347건, 'N개 한정' 284건)
- 구성: [게릴라] + 수량 한정 + 마감 시각 + 품질 설명 1~2줄 + 링크
- 예: "기다렸다 사면 늦어요… [게릴라] ○○ 2kg 12,500원 100개 한정"

**③ 품절·종료·재오픈**
- 품절 소식 자체를 다음 회차 홍보에 활용
- 예: "5분컷으로 종료했어요" → "오픈 시마다 바로 품절! 수요일 출고로 50개 오픈합니다"

**④ 배송 안내**
- 3줄 고정: 발주 마감 / 발송 마감 / 재개일
- 새벽시장 글에는 📣 줄로 고정 배치

**⑤ 신상품·첫수확**
- 희소성을 앞세움: "[오늘부터 수확 시작!] 시중에 잘 안 풀리는 한정 품목"
- 2026년 단품 글은 스펙 카드 형식: `★상품명★ / 판매가 / 배송비 / 합포장 N개`

## 2. 운영 리듬

| 지표 | 값 |
|---|---|
| 하루 게시 수 (게시일 기준) | 평균 6.1, 중앙값 4. 2022년 4.3 → 2024년 5.6 → 2026년 9.0 |
| 요일별 평균 | 수 8.0 > 목 7.1 > 화 6.8 > 금 5.7 > 월 5.6 > 토 4.1 > 일 3.2 |
| 피크 시각 | 11시 (전체의 21%). 새벽시장 공지 시각 중앙값 11:20 |
| 단품 글 시간대 | 17~21시가 28~33%. 21~24시 비중은 2022년 9% → 2026년 15%로 증가 |

- **새벽시장 요일**: 2022년 월~금 매일 → 2023년부터 월·수·금 주 3회
- **주문 마감**: 새벽시장은 당일 14:00. 행사·게릴라는 익일 09:00이 표준
- **출고**: 영업일 1~2일 내, 13:30까지 들어온 주문은 당일 발송
- **밤 정리 글**: 하루 제안을 모아 다시 올리는 요약 글이 따로 있음

## 3. 가격 전략

**가격대** (가격 표기 24,269건)

| 가격대 | 비중 |
|---|---|
| 1만원 미만 | 6% |
| 1~2만원 | 23% |
| **2~3만원** | **37%** |
| 3~4만원 | 19% |
| 4만원 이상 | 15% |

- 가격 끝자리: ○,500원 50%, 천원 단위 41%, ○,900원 7% (○,900원은 가공품·밀키트)
- **배송비 표기 변화**: `+택배비` (2022) → "택포" (2024) → "배송비 포함" (2025~26) → 배송비·합포장 개수 따로 표기 (2026)
- **세트 구성**: 2인/3인 밀키트, 1+1 (2025~26년 급증), 5+1 행사
- **할인 표현**
  - 기준가 대비: "판매가 → 공구가", "오픈가 → 행사가"
  - 마진 강조: "노마진", "원가판매"
  - 희소성: "N박스 한정"
  - 2026년 등장: 투표로 수요를 확인한 뒤 공구 오픈 ("50개 이상 모이면 진행")

## 4. 주문 수집 방식 변화

| 시기 | 방식 |
|---|---|
| 2022 | 계좌 입금 + 구글폼 + 스마트스토어 + 밴드 |
| 2023~24 | 스마트스토어 중심 |
| **2024-11** | **스마트스토어 영구 운영정지** |
| 2025-01 | 자사몰 오픈 |
| 2025-03 | 자체 앱 출시 (쿠폰·푸시 알림) |
| 2025-05 | 새벽시장만 카톡채널 수기주문서 + 입금 방식으로 되돌림 |
| 2026 | 자사몰 중심, 10회 이상 구매자 대상 VIP방·쿠폰 운영 |

- **정지 사유 (2024-11)**
  1. 농가 바코드 오류로 택배 미집화
  2. 그 결과 장기 미발송
  3. 판매자 일방 취소 + 가송장 입력 민원 누적
  4. 앞서 예약 상품의 폭우 낙과 취소 민원도 쌓여 있었음
- **새벽시장만 되돌린 이유**: 매일 바뀌는 경매 상품을 상품페이지 옵션으로 관리하려면 오전마다 옵션 수정과 사진 교체에 시간이 너무 많이 듦

## 6. CS 문구 패턴
- **택배파업**: 배송 불가 지역 안내 → 3일 뒤 대체 택배로 전환 안내
- **명절 지연**: "2~3일 후 도착, 양해 부탁드려요"
- **기상 이슈**: 접수 불가 지역 개별 안내
- **주문 폭주**: "30일 내 순차 발송" 또는 "취소 승인" 중 고객이 선택 → 보상쿠폰 → 대체 사이즈 행사
- **품절 후 접수 고정 문구**: "금액조정 / 이후출고 / 환불 또는 적립"
- **맛 보장 범위**: "맛 때문이면 환불 가능, 모양·크기 때문이면 불가"
- **사전 지연 고지**: 첫 발송·농번기 지연 가능성 미리 안내
- **사후 보상**: 소량 서비스품을 보내 단골로 전환한 사례

## 7. 맛가득 적용 TOP 7
1. **스펙 카드 고정**: 판매가 / 배송비 / 합포장 / 중량·과수·brix / 출고일. 글 1개 = 상품 1개 = 링크 1개
2. **마감·출고 고정 시각 하나를 모든 공지에 표기**
3. **딸기 중량 사다리**: 500g×2 / 1kg / 2kg, 가정용과 선물용 구분, 가격 끝자리 ○,500 / ○,900
4. **수량 한정 게릴라 → "○분 만에 종료" 공지**로 다음 회차 기대감 만들기
5. **플랫폼 정지 방지**: 가송장·일방 취소 금지, 예약 상품 기상 리스크 고지, 백업 주문 경로 확보
6. **시즌 캘린더**: 11월 첫 출하 → 1월 설 D-10 발송 마감 → 2월 피크 게릴라. 비시즌에는 가공품으로 알림 유지
7. **CS 문구 세트화 + 보상 규칙**(적립금·소량 서비스) 사전 정의
