# 부록 A. 드짜영짜방 (유튜브 쇼츠·드라마·영화 수익화) 분석

- 범위: 2025-03 ~ 2026-10, 메시지 약 6.9만 건
- 성격: 강의 업체 운영진의 공지·홍보·후기·입장 관리가 대부분. 판매 흐름은 무료특강 → 다시보기(3~5만원) → 정규강의(100만~199만원).
- 쓸 만한 실무 노하우는 소수 실무 멤버의 답변에 몰려 있음.
- **수익 수치는 대부분 본인 주장·홍보이며 검증되지 않음.**
- 화자 닉네임은 '멤버'로 일반화.

## 1. 수익화 모델과 보고된 수치

**쇼츠 조회수 수익 (애드센스)**
- 1,000회당 약 $0.15~0.2 (2025-04)
- 영드짜 RPM 약 390원 → 유효조회 1,000만이면 약 390만원 (2026-02)
- 쇼츠 월 5천만 회 ≈ 약 1,000만원 (2026-07)
- 다채널(5개)로 월 약 1억 회, 수익 감소 추세 (2025-10)
- 국가별 단가: 일본 높음, 인도 낮음

**음원 수익**
- 2025-03 단가가 1/5~1/10로 하락, 일부 서비스는 2025-05 종료
- 2026-03 기준 "음원 수익은 사라졌고, 조회수와 쇼핑태그로 번다"

**영화·드라마 리뷰**
- 트래픽 최대 카테고리
- 영화 롱폼 월 수천만원을 자기 인증한 사례 있음 (2026-06~08, 미검증)

**쇼핑쇼츠 (유튜브 쇼핑태그·쿠팡파트너스)**
- 2026 강세. "허위콘텐츠 정지 바람 속에서도 살아남는다"
- 쇼핑태그는 구독자 1만 이상에서 활성화된다는 보고 (2025-06)

**시니어 롱폼 (사연·야담·정보성)**
- 2025 하반기 붐 → 2026-01 '허위 콘텐츠' 사유 대량 정지

**정치 쇼츠**
- 공공 채널 영상(화이트리스트) 활용 (2026-02~08)

**유튜브 외 수익원**
- 네이버 클립 + 쇼핑커넥트, 스레드, 이베이, 사주, 전자책

**협찬**
- 소형 채널이 쇼츠 1편에 88만원을 받았다는 칼럼 (2026-07)
- 화이트리스트 캠페인 약 20만원 (구독자 1만 이상, 2025-05)

**다채널 규모화**
- 채널 수십~150개를 외주로 운영하는 사례

## 2. 제작 도구와 워크플로

| 분류 | 도구 |
|---|---|
| 편집 | 캡컷(압도적, 4K HDR 출력 팁), 프리미어, Vrew, 미리캔버스·이미지FX(썸네일) |
| 대본 | ChatGPT GPTs, 제미나이 Gems, 클로드(Projects·스킬·Claude Code), 젠스파크, NotebookLM |
| TTS | 타입캐스트, 일레븐랩스, 구글 AI 스튜디오 TTS (길어지면 말이 빨라지는 문제). 고수는 **직접 더빙** |
| 생성 | 클링, Veo, 소라2, 그록, 시댄스2, 힉스필드, 미드저니, 나노바나나, comfyUI |
| 자동화 (2026 하반기) | MCP 연동(클로드·타입캐스트), 바이브코딩(안티그래비티, Cursor), Opal, Codex, 에이전트형 제작 툴 |
| 소재 발굴 | VidIQ, 구글 렌즈, 더우인 (P2P·녹화는 위법 소지) |

**대표 워크플로**
- **영화 롱폼**
  1. 작품 선정 챗봇
  2. 클로드에 자막 파일 입력 → 대본과 편집점 타임스탬프 역산
  3. 일레븐랩스로 음성 생성
  4. 캡컷 편집
  5. 문체만 바꿔 2차 롱폼과 쇼츠로 재활용
- **일본 쇼츠**
  1. VidIQ로 소재 발굴
  2. Gems로 분석·현지화 번역
  3. 타입캐스트로 음성 생성
  4. 캡컷 편집 (일본식 폰트·효과음)

**외주 단가**: 쇼츠 1편 1.5만원 (2025-11), 정치 영상 1편 3,200원 (2026-08), AI 생성 영상 1편 약 400원 (2026-09)

## 3. 저작권·재사용·정지

**시기별 흐름**
- 2025-03-31: 쇼츠 조회수 집계 방식 변경. 수익·파트너 자격은 계속 몰입도 조회수(engaged views) 기준
- 2025-06: 영드짜 대형 채널 대량 삭제
- 2025-07-15: 정책 강화 후 영화 채널 정리
- 2025-10: '스팸·사기·현혹' 사유로 채널 삭제. 고정댓글로 OTT 시청을 유도하면 스팸 처리된다는 전언
- 2026-01~02: 롱폼 '허위 콘텐츠' 수익정지 대량 발생, 항소 통과는 드묾
- 2026-05 전후: 재사용 판정 집중

**회피법**
- 업로드 단계의 정책 표시: 컷을 잘게 나누고, 원본 장면을 길게 쓰지 않고, 음악을 피하고, 원본과 차별화
- 저작권 경고 3회면 채널 삭제. 권리자가 아닌 사람의 신고는 반론통지로 대응 (7일 내 미증빙 시 경고 소멸)
- 재사용 사유 수창 거절 시 항소 영상에 **작업 과정·대본·타임라인** 공개 (본인 소개 30초 등)
- 같은 배급사 작품 연속 업로드는 위험
- 연좌 정지 대비: 애드센스·계정·IP 분리. 구매한 채널은 '시한폭탄'
- 노출 제한 요소: 피·노출·폭력·사망 뉘앙스·어린이. 신규 채널일수록 민감하므로 제목도 안전하게

## 4. 알고리즘·운영 팁
- **수창 조건**: 쇼츠는 90일 유효조회 1,000만 + 구독자 1,000, 롱폼은 시청시간 4,000시간. 첫 수창은 롱폼이 쉽다는 의견
- **빈도**: 초기 1일 1편. 여력이 생기면 다채널로 분산. 하루 2~4편 이상은 '공장' 인식 위험
- **업로드 시간**: 크게 중요하지 않다는 의견 다수
- **결 유지**: 같은 작품·배우로 이어가고, 소재가 남으면 조회수가 출렁여도 지속
- **길이**: 1~3분 쇼츠가 RPM이 높다는 주장
- **기타**: 첫 1~3초 훅. 제목에 태그 넣지 않는 추세. 단톡방에 자기 채널 공유는 역효과

## 5. 2026 하반기 트렌드
- **수창 기준 강화설**: "2027-02-01 신규 채널 조건 변경", "쇼츠 2천만 뷰 + 3개월마다 1천만 유지" — **공식 확인 필요**
- **AI 에이전트화**: "영상 제작자에서 시스템 운영자로"라는 구호. 반론은 "AI로 하루 1,000개 올려도 조회수 안 나온다 — 결국 소재와 기획"
- **카테고리 이동**: 시니어 롱폼 → 영화 롱폼·쇼핑쇼츠·일본·해외 멀티유즈·정치·노멀쇼츠
- **진정성 부각**: 직접 더빙·직촬 (직촬 10편으로 월 400만원을 주장한 사례)
